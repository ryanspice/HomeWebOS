# Geometric Blue local theme fixture

`demo.html` is an offline browser illustration with six selectable semantic icons;
it is not a native or TV screenshot. Open it directly from disk. All images are
original geometric shapes and gradients generated by `make_demo.py` using Pillow;
there are no third-party images or distributed fonts. `geometric/source.json` is
the editable local input. `demo-data/themes` is a prepared, hash-verified snapshot
for the C++ loader and native startup tests. The launcher can now select that
store explicitly with `--theme-data`; it applies at the next launch.

From the project root, with an already installed Pillow:

```powershell
python tools/prepare_theme.py --data-dir demos/themes/demo-data verify
node demos/themes/demo_check.cjs
```

To make a separate local selection in an app-owned data directory, replace
`<APP_DATA_DIR>` with that directory. Only its `themes/` child is written.

```powershell
python tools/prepare_theme.py --data-dir <APP_DATA_DIR> import demos/themes/geometric/source.json
python tools/prepare_theme.py --data-dir <APP_DATA_DIR> verify
python tools/prepare_theme.py --data-dir <APP_DATA_DIR> default
python tools/prepare_theme.py --data-dir <APP_DATA_DIR> previous
```

The example `com.example.geometric` ID is a mapping fixture, not an inventory
claim. Unsupported p5theme archives, DDS/zstd, SVG, sound and video are rejected.
See [native theme usage](../../docs/NATIVE-THEMES-IMPLEMENTATION.md) for startup
loading, fallback, resource limits and native evidence. This HTML illustration
does not itself change a running launcher or operate the TV.
