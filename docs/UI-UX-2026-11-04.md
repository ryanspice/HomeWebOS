# Native collection UI/UX follow-up — 2026-11-04

Scope: `B:\Dev\webos\spice-home-cpp` only. The C++ deck remains the implementation
target; the 50 concepts remain an unreviewed POC and a porting guideline. This pass
does not establish feature parity with every Rust feature or TV deployment readiness.

## Resulting behavior

- **Settings → Browse 50 design concepts** opens the collection without a CLI flag.
  Back returns to that Settings control; a subsequent Back restores the Home control
  that opened Settings. The approved rail, staircase and five bottom cards retain
  their geometry.
- **Search concepts** opens a native A–Z / 0–9 keyboard, with Space, Delete letter,
  Clear and a result-count button. D-pad/OK and pointer use the same hit rectangles.
  Back closes search while preserving the query. Hardware typing is also enabled
  through SDL text input, with C/E/M/T/F launcher shortcuts suppressed in the catalog.
- Every collection control has a visible focus ring. Choosing a category keeps
  focus on its chip. Search resets paging and retains a valid focused item; UTF8
  deletion removes one code point, and deleting an empty query keeps the catalog open.
- Clear removes the query while retaining the category. Empty results provide a
  separate reset action for both query and category. Paging states the actual visible
  range, and disabled Previous/Next buttons are absent from the focus/hit target list.
- Inspector Back restores the selected tile, including after wrapping to another page.
  Counts and long filter text stay within their footer area. The Back label fits its
  control. Catalog/inspector copy identifies concepts and sample content without
  exposing implementation-version notes in the user flow.

The bounded catalog loads at startup, before interactive frames. Activation IDs and
preferred focus IDs are copied before rebuilding the node list, so rebuilding cannot
invalidate a referenced ID while the activation or focus-restoration code still uses it.
No dependencies, settings schema, service routes or device mappings were added.

## Reproduction

```bash
cmake --build build/desktop --parallel 4
ctest --test-dir build/desktop --output-on-failure
LIBGL_ALWAYS_SOFTWARE=1 MESA_GLES_VERSION_OVERRIDE=2.0 \
  xvfb-run -a -s '-screen 0 3840x2160x24' \
  python3 tests/native_qa.py --binary build/desktop/spice-home-cpp \
  --assets assets --out evidence/catalog-ux/native

cmake --build build/san --parallel 4
ctest --test-dir build/san --output-on-failure
ASAN_OPTIONS=detect_leaks=0:halt_on_error=1 UBSAN_OPTIONS=halt_on_error=1 \
  LIBGL_ALWAYS_SOFTWARE=1 MESA_GLES_VERSION_OVERRIDE=2.0 \
  xvfb-run -a -s '-screen 0 1920x1080x24' \
  ./build/san/spice-home-cpp --assets assets --frames 40 \
  --config /tmp/spice-catalog-ux-recheck.json \
  --script evidence/catalog-ux/search-edit-return.json \
  --report /tmp/spice-catalog-ux-recheck-report.json
```
